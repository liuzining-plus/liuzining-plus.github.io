## C语言指针

**指针是什么** 指针变量是指像一个特定地址的变量

```c
int a = 10;      
int *p;      //这里是声明一个指针变量
p = &a;          // 把 a 的地址给 p 现在说明p指向a了
```

当我们来定义一个变量的时候 `int *p` 说明p是一个指针变量

那么单独的 `*p` 里的是 `*` 是什么

这里 `*` 是**解引符** 以我上面的为例 `*p` 即取出p这个指针（即地址）存放的值

`p = &a;` // 把 a 的地址给 p 现在说明p指向a了 因为这一行所以 `*p = 10`

`printf("%d", *p);` 用printf函数打印出来的也是10

那么你现在应该不知道为什么要用指针 到这里应该觉得没啥用 我来举几个例子

```c
void change(int x) {
    x = 99; 
}

int main() {
    int a = 10;
    change(a); 
    // 结果：a 还是 10
}
```

**为什么a还是10**

我们看第一个函数 `change()` 里面更改的是X （即X=99）

虽然我们传入了a 但是第一个函数还是对x进行操作 与a无关

```c
void change(int *p) {
    *p = 99; 
}

int main() {
    int a = 10;
    change(&a); 
}
```

`change(&a)` 为什么要传入 `&a` 因为 `change(int *p)` 这个里面要求传入一个指针变量（即传入一个地址）

`&` 是**取地址符** `&a` 就是a的地址 所以传入这个 `*p = 99` 指让这个地址里存入的值变为99

`change(&a)` 我们这样 就让a地址里的值变为了99

那么a 就是99了 因为变量的值实际上是存在它的地址里的

还有就是**减少内存占用** `GPIO_Init(GPIOA,&GPIO_Initstructure)`

我这样用地址 就不需要把 `GPIO_Initstructure` 里的一大串东西重新存入内存一遍

## 指针补充部分

-   还记得指针部分吗 int \* p
-   这说明p是一个指针 但你想过int 的意义吗 感觉你会将这与 int a = 10 类比
-   int a = 10 这是定义了一个int型的变量 a 且让它为10
-   那么你会不会想 int \* p是定义了一个int 型的指针变量
-   并不是 这是说明 p这个指针指向了一个int型的变量 类似char \*p 就是说这个指针指向了一个char 型的变量
-   那么指针到底占多少位了 这取决与你的计算机是多少位的系统 一般的电脑都是32位系统
-   这说明用32个二进制来表示一个地址 那么指针就是4个字节 一个字节位8位 （0000 0000）~~8个二进制数~~
