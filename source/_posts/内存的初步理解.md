```c
#include <stdio.h>

int main ()
{
    int x = 3;
    int y = 2;
    int z = x + y;
    printf ("z = %d",z);
    return 0;

}
```

**这是最基础的c语言代码**

```plaintext
.LC0:
        .string "z = %d"
"main":
        push    rbp
        mov     rbp, rsp
        sub     rsp, 16
        mov     DWORD PTR [rbp-4], 3
        mov     DWORD PTR [rbp-8], 2
        mov     edx, DWORD PTR [rbp-4]
        mov     eax, DWORD PTR [rbp-8]
        add     eax, edx
        mov     DWORD PTR [rbp-12], eax
        mov     eax, DWORD PTR [rbp-12]
        mov     esi, eax
        mov     edi, OFFSET FLAT:.LC0
        mov     eax, 0
        call    "printf"
        mov     eax, 0
        leave
        ret
```

`mov DWORD PTR [rbp-4], 3` 给这一块内存 存入一个值 3 ~~int x = 3;~~

`mov DWORD PTR [rbp-8], 2` 给这一块内存 存入一个值 2 ~~int y = 2;~~

`mov edx, DWORD PTR [rbp-4]` ==读取`[rbp-4]`的值给edx 即edx=3== edx 是cpu内的通用寄存器 GPR

`mov eax, DWORD PTR [rbp-8]` ==读取`[rbp-8]`的值给eax 即eax=3==

\[rbp-4\] \[rbp-8\] \[rbp-12\] 这是内存 存储的内容==在ram中==

`add eax, edx` 即`eax = eax + edx` 5 = 2 +3

`mov DWORD PTR [rbp-12], eax` ==读取eax的值给`[rbp-12]`\==

可以看到 具体的运算是在cpu 里完成 但是cpu 的GPR有限 所以运算中的值存储在ram里
